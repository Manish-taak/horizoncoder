2. grid-column & grid-row (Line Numbers)

Grid mein invisible lines hoti hain — columns ke liye 1,2,3… aur rows ke liye bhi 1,2,3… . grid-column: 1 / 3 matlab "column line 1 se shuru ho, line 3 pe khatam ho" (yani 2 columns cover karo). grid-row: 1 / 3 bhi same tarah kaam karta hai rows ke liye. Isse aap kisi bhi item ko kisi bhi jagah stretch kar sakte ho bina areas ka naam diye.

col 1–3 / row 1–3
col 3–4 / row 1–4
col 4–5 / row 1–5
col 1–3 / row 3–5
col 3–4 / row 4–5

3. order Property

HTML mein items ka order hai: A → B → C → D → E.
Lekin order property lagane ke baad visual order ho jaata hai: E → A → D → B → C.
Default order: 0 hota hai. Chhoti value = pehle dikhai deta hai. Negative values bhi chalti hain.

4. justify-items & align-items (Alignment)

justify-items: center → har item apni cell ke andar horizontally center ho jaata hai.
align-items: center → har item apni cell ke andar vertically center ho jaata hai.
Dono milake item ko perfectly center karte hain. Values: start, end, center, stretch (default).
