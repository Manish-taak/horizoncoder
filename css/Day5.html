Section 04

flex-wrap

Jab items container mein fit na hon toh kya karein?
nowrap = compress karke ek line mein raho (default).
wrap = agli line pe chale jao (jaise text wrap hota hai).
wrap-reverse = wrap hoga lekin upside-down.

Section 06

align-self

align-items container pe lagata ho — saare items ek saath.
align-self ek single item pe lagata ho — sirf wahi item override hoga.
Neeche dekho — har item ki apni alag align-self value hai.

.item-1 { align-self: flex-start; }  .item-2 { align-self: center; }  .item-3 { align-self: flex-end; }  .item-4 { align-self: stretch; }

Section 07

flex-grow & flex-shrink

flex-grow: agar space bachta hai toh kaunsa item kitna bada ho?
Number jitna zyada = utna zyada share milega extra space ka.
flex-shrink: agar jagah kam ho toh kaunsa item kitna chhota ho? (default: 1)
flex-basis: item ki starting/base size (like width/height).
Shorthand: flex: grow shrink basis — e.g. flex: 1 = grow:1, shrink:1, basis:0

.item-1 { flex-grow: 1 }  .item-2 { flex-grow: 2 }  .item-3 { flex-grow: 1 }
Total parts = 4 → item-2 ko double share milega
grow:1
grow:2
grow:1

flex: 0 0 auto = item na badhega na chhota hoga (fixed size).
flex: 1 = equal share of space (responsive layout ke liye sabse common use).

flex:0 0 120px
flex:1
flex:1

Section 08

order

HTML mein items ka order hai 1→2→3→4→5.
order property se visual order change hota hai — HTML same rehta hai.
Default value = 0. Chhoti value pehle dikhti hai. Negative bhi chalti hai.

HTML order: 1, 2, 3, 4, 5
.item-1{order:3}   .item-2{order:1}   .item-3{order:5}   .item-4{order:2}   .item-5{order:4}
Visual order: 2 → 4 → 1 → 5 → 3

2order:1
3order:5
4order:2
5order:4
