CSS Positions (Modern & Easy)

📌 position: relative

Definition: position: relative ka matlab hai element apni original (default) jagah par hi rehta hai, lekin tum usko top, left, right, bottom se thoda move kar sakte ho.

Samajhne ka tarika: Element apni jagah reserve karke rakhta hai, bas visually shift hota hai.

Relative

📌 position: absolute

Definition: position: absolute element apni jagah chhod deta hai aur nearest positioned parent (jiska position relative/absolute/fixed ho) ke according place hota hai.

Samajhne ka tarika: Agar parent par position: relative laga hai to child uske andar move karega, warna body ke according.

Absolute

📌 position: sticky

Definition: position: sticky ek hybrid hai relative aur fixed ka. Jab tak scroll normal hai tab tak relative jaisa behave karta hai, aur ek point (top: 0) par pahunchte hi fixed ho jata hai.

Samajhne ka tarika: Scroll karte waqt element upar chipak jata hai.

Sticky

📌 position: fixed

Definition: position: fixed element viewport (screen) ke according fix ho jata hai aur scroll hone par bhi apni jagah nahi badalta.

Samajhne ka tarika: Jaise WhatsApp chat button ya floating help button hamesha screen par dikhta hai.

Fixed
