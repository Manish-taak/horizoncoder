Media Queries (Easy + Visual)

📌 Media Query

Definition: Media Query CSS ka feature hai jo different screen sizes ke liye alag styles apply karta hai.

Samajhne ka tarika: Mobile, Tablet, Laptop ke liye alag design banana.

max-width: Screen choti hone par style apply hota hai (Mobile-first approach).
min-width: Screen badi hone par style apply hota hai.

📌 Hover Media Feature

hover: hover → Mouse devices (Laptop/Desktop)
hover: none → Touch devices (Mobile)

👉 Desktop par hover karo → color change hoga
👉 Mobile par hover nahi hota → default color dikhega
