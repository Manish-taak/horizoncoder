📌 calc()

Definition: calc() ek CSS function hai jo tumhe dynamic calculations karne deta hai (px, %, vh mix karke).

Samajhne ka tarika: Layout ko flexible banana — jaise "50% width minus spacing".

Example: width: calc(50% - 20px)
