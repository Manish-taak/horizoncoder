z-index & object-fit (Easy + Visual)

📌 z-index

Definition: z-index decide karta hai kaunsa element upar dikhega aur kaunsa neeche (stacking order).

Important Rule: z-index sirf tab kaam karta hai jab element par position (relative, absolute, fixed, sticky) laga ho.

Samajhne ka tarika: Socho cards ek dusre ke upar rakhe hain — jiska z-index jyada hoga wo sabse upar dikhega.

📌 object-fit

Definition: object-fit
Samajhne ka tarika: Image ko box ke andar adjust karna — crop karna hai, stretch karna hai ya pura dikhana hai.

fill (default) → image stretch/squish ho sakti hai

contain → pura image dikhega (empty space aa sakta hai)

cover → box fill karega (image crop ho sakti hai)

none → image resize nahi hoti

scale-down → contain ya none me se chhota choose karta hai
